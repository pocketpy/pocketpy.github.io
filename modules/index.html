Module reference

pocketpy includes a focused set of Python modules and game-oriented extensions. These pages describe the APIs shipped in this repository, including differences from CPython. They are not a reference to the full Python standard library.

Most native functions accept positional arguments. Examples show supported call forms; see the argument rules.

Data and algorithms

Module Use
bisect Binary search and insertion into sorted lists.
collections Counts, default dictionaries, and double-ended queues.
dataclasses Small data classes from annotations.
enum Named constants.
functools Caching, reductions, and partial calls.
heapq Min-heaps and priority queues.
operator Operators and accessors as functions.
typing Placeholders for type hints.

Numbers, time, and text

Module Use

Optional native modules

These modules default to off in CMake. See build configuration for enabling them and initializing native dependencies.

Module Required option
cute_png PK_BUILD_MODULE_CUTE_PNG=ON
lz4 PK_BUILD_MODULE_LZ4=ON
msgpack PK_BUILD_MODULE_MSGPACK=ON
periphery PK_BUILD_MODULE_PERIPHERY=ON, Linux target

A host application may add or replace modules. If an import fails, check the running build's capabilities and module loader. Installing a CPython package does not automatically make it available to pocketpy.
